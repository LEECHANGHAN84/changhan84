suk upload

suk upload는 유튜브 채널 금요일오후다섯시 운영자가 자기 채널을 관리하려고 쓰는 개인용 도구입니다.

  • 운영자가 직접 만든 영상을 자기 유튜브 채널에 업로드하고 공개 시각을 예약합니다.
  • 업로드한 영상의 제목·설명·썸네일을 정리합니다.
  • 자기 채널 영상에 달린 댓글을 읽고 답글을 답니다.

이 도구는 일반 사용자에게 제공하는 서비스가 아니며, 채널 운영자 본인의 Google 계정으로만 로그인해 사용합니다. YouTube API 서비스를 사용하며, YouTube 서비스 약관을 따릅니다.
