이 앱은 운영자 본인의 유튜브 채널에 영상을 올리고 예약하기 위한 개인용 도구입니다. 운영자 외의 사용자를 대상으로 하지 않습니다.

1. 사용하는 정보

  • 운영자 본인의 유튜브 채널 정보(채널 이름, 영상 목록, 조회수 등 통계)
  • 업로드할 영상 파일과 제목·설명·태그·공개 설정 등 메타데이터

2. 사용 목적

운영자 본인 채널에 영상을 업로드·예약·수정하고, 업로드 결과를 확인하는 용도로만 사용합니다.

3. 저장과 보관

Google 로그인 토큰과 업로드 기록은 운영자의 컴퓨터에만 저장되며, 별도 서버로 전송하거나 보관하지 않습니다.

4. 제3자 제공

어떤 정보도 제3자에게 제공하거나 판매하지 않습니다. 데이터는 Google(YouTube Data API)과만 주고받습니다.

이 앱이 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
